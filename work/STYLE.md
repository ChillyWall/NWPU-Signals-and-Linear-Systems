## 3. 标题层级（markdown → pandoc → LaTeX article 类）

- `#` 只用于章：写作 `# 绪论`、`# 连续时间系统的时域分析`……
  **不要写"第一章"字样**，编号由 LaTeX 自动生成。
- `##` 章内固定四段，顺序与名称不得改动：
  1. `## 考点清单`
  2. `## 核心概念与公式`
  3. `## 典型题型与解法`
  4. `## 易错点`
- `###` 题型条目：`### 题型 2-3 由微分方程求零输入响应`
  命名格式：`题型 <章号>-<序号> <一句话问题特征>`
- `###` 也用于"核心概念与公式"里的主题小节，如 `### 冲激响应与阶跃响应`。
- **标题里不写节号**（不要写 `### 2.4 冲激响应与阶跃响应`）：编号一律由 LaTeX 自动生成，
  手写编号会与之叠加成"2.2.4 2.4 …"。
- **交叉引用不写节号**（不要写"见 2.6 节"）：写成"见'卷积积分限的确定'一节"。
  唯一的例外是引用课件原文页码/节号，此时必须写清"课件 2.6 节"，与本书节号区分开。
- `####` 尽量不用。

## 4. 各段写法

### 4.1 考点清单
一张表，管住"考什么、怎么考、多重"：

```
| 考点 | 常见考法 | 重要度 |
|:-----|:---------|:------:|
| 零输入响应的求解 | 给微分方程与初始条件，求 $y_{zi}(t)$ | ★★★ |
```

重要度只用 ★ / ★★ / ★★★ 三档，直接写星号字符。

### 4.2 核心概念与公式
- 概念用一句话定义 + 一句"什么时候用"。
- 公式必须给**成立条件**（如"仅当 $f(t)$ 满足狄利克雷条件"、"收敛域 $\mathrm{Re}(s)>\sigma_0$"）。
- 性质表用 pipe 表格，列数 ≤ 5。
- 不重复课本大段推导；但"记不住就用不了"的推导保留 3–5 步。

### 4.3 典型题型与解法
每个题型固定四块：

```
### 题型 3-2 利用傅里叶级数求周期信号频谱

**题型特征**：题目给出非正弦周期信号（波形图或分段表达式），要求频谱/带宽/功率。

**解题步骤**：
1. 判断周期与周期 $T$，写出基频 $\omega_0=2\pi/T$。
2. ……

**例题**（【附加作业3 第4题】）：
（完整解答，每步给公式 + 一句理由）

**同类题**：
- 【附加作业3 第2题】只需求三角形式系数，用偶函数性质省掉 $b_n$，见公式 (3-7)。
```

- **例题**取本块负责的附加作业中的典型题，必须**完整解答**：写清每一步的公式、代入数值、最终结果（含单位）。
- **同类题**只给关键思路（一行一题），但**本块负责的每道作业题都必须在文中出现一次**（精解或同类题提示），不得遗漏。
- 出处标注统一 `【附加作业2 第5题】`。
- 波形类题目无法插图：用分段函数 + 关键点坐标（如"$t=0^-$ 处 $f=1$，$t=1$ 处跳变到 $0$"）描述清楚。

### 4.4 易错点
用有序列表，每条格式：**错误做法** → 正确做法 → 一句话原因。优先收作业里真实踩过的坑。

## 5. 数学书写规范（最容易翻车，逐条照做）

- 行内 `$...$`，行间 `$$ ... $$`；行间多行用 `$$ \begin{aligned} ... \end{aligned} $$`。
- 所有 `$` 必须成对；上下标多字符一律加花括号：`y_{zs}`、`\omega_{0}`、`F^{n}`。
- 数学模式里**不出现中文**。要写中文说明就跳出公式写在句子里。
- 只用 amsmath 提供的环境：`aligned`、`cases`、`pmatrix`、`bmatrix`、`matrix`、`array`。
- **禁止**：`\bm`、`\boldsymbol`、`\mathbb`、`\ce`、`\SI`、`tikz`、`\begin{align}` 的编号依赖。
- 只有 `$$...$$` 支持编号与交叉引用（`{#eq:xxx}`），行内公式不编号。

### 记号强制统一

| 概念 | 记号 | 备注 |
|:---|:---|:---|
| 连续时间信号 / 响应 | $f(t)$、$y(t)$ | 激励也可用 $e(t)$，同一节内保持一致 |
| 离散信号 | $f(n)$ | |
| 单位阶跃 | $u(t)$、$u(n)$ | 全篇用 $u$，不要混用 $\varepsilon$ |
| 单位冲激 | $\delta(t)$、$\delta(n)$ | |
| 零输入 / 零状态响应 | $y_{zi}(t)$、$y_{zs}(t)$ | 下标正体斜体均可，但要统一 |
| 完全响应 | $y(t)=y_{zi}(t)+y_{zs}(t)$ | |
| 自然 / 受迫响应 | $y_{n}(t)$、$y_{f}(t)$ | |
| 冲激 / 阶跃响应 | $h(t)$、$g(t)$ | |
| 卷积 | $f_1(t)*f_2(t)$ | 不用 $\ast$ |
| 傅里叶变换 | $F(\mathrm{j}\omega)=\mathcal{F}[f(t)]$ | |
| 拉普拉斯变换 | $F(s)=\mathcal{L}[f(t)]$ | |
| 系统函数 | $H(s)$、$H(\mathrm{j}\omega)$ | |
| 虚数单位 / 自然底 | $\mathrm{j}$、$\mathrm{e}$ | 正体 |
| 微分算子 | $p$ | |
| 抽样函数 | $\mathrm{Sa}(x)=\dfrac{\sin x}{x}$ | 首次出现说明等价于 $\mathrm{sinc}$ 定义 |
| 单位 | $\mathrm{V}$、$\mathrm{A}$、$\mathrm{rad/s}$、$\mathrm{Hz}$ | 一律 `\mathrm` |

函数名用 `\sin`、`\cos`、`\tan`、`\ln`、`\exp`、`\max`、`\min`；不要写成斜体字母串。
