# 前言：这条课程主线只有一句话 {.unnumbered}

给定激励 $f(t)$ 与线性时不变（LTI）系统，求响应 $y(t)$。

六个章节都在回答这同一个问题，区别只在于**用什么坐标去描述信号**。把这句话想通，全书的公式就不是一百个孤立结论，而是三套坐标下的同一件事：

- **时域坐标**：把信号拆成冲激的叠加，系统对 $\delta(t)$ 的响应是 $h(t)$，于是响应是叠加积分——卷积。
- **频域坐标**：把信号拆成复正弦 $\mathrm{e}^{\mathrm{j}\omega t}$ 的叠加（傅里叶级数对周期信号、傅里叶变换对非周期信号），系统对每个频率只做"乘一个复数"的加权，加权系数就是 $H(\mathrm{j}\omega)$。
- **复频域坐标**：把信号拆成 $\mathrm{e}^{st}$ 的叠加（拉普拉斯变换），系统对 $\mathrm{e}^{st}$ 的响应仍是 $\mathrm{e}^{st}$ 乘一个数 $H(s)$，于是微分方程变成代数方程。

三套坐标通过"卷积定理"和"系统函数"缝合在一起：

$$
y(t)=f(t)*h(t)
\qquad\Longleftrightarrow\qquad
Y(\mathrm{j}\omega)=F(\mathrm{j}\omega)\,H(\mathrm{j}\omega)
\qquad\Longleftrightarrow\qquad
Y(s)=F(s)\,H(s)
$$

这三条等号是全部章节的骨架。考试里任何一道"求响应"的题，本质上都是在这三条里挑一条最短的路走。

## 六章知识地图 {.unnumbered}

| 章 | 回答的问题 | 核心工具 | 关键结论 |
|:---|:---------|:---------|:---------|
| 第一章 绪论 | 信号与系统各自怎么描述 | 信号的基本运算、奇异函数、LTI 判定 | 线性＝齐次性＋可加性；时不变＝参数不随时间变 |
| 第二章 时域分析 | 不解变换，直接求响应 | 微分方程、算子 $p$、卷积 | $y(t)=y_{zi}(t)+y_{zs}(t)$，$y_{zs}(t)=f(t)*h(t)$ |
| 第三章 正交分解 | 信号为什么能拆成三角函数之和 | 正交函数集、傅里叶级数 | 周期信号频谱离散；帕塞瓦尔定理给出功率分配 |
| 第四章 频域分析 | 非周期信号怎么办 | 傅里叶变换、$H(\mathrm{j}\omega)$ | 时域卷积＝频域相乘；无失真传输与抽样定理的条件 |
| 第五章 复频域分析 | 傅里叶变换不收敛的信号怎么办 | 拉普拉斯变换、部分分式、$s$ 域电路 | 微分方程→代数方程；收敛域决定信号类型 |
| 第六章 系统函数 | 不看输入，只看系统本身 | 零极点、罗斯判据 | 极点位置决定响应波形与稳定性 |

一句话概括六章的关系：**第二、三、四、五章是四种"求响应的算法"，第六章是反过来"由响应看系统本质"。**

## 三条贯穿全程的恒等式 {.unnumbered}

1. **卷积定义**是时域一切结论的源头，卷积的四个性质（交换、分配、结合、与冲激/阶跃的关系）必须张口就来：
   $$
   f_1(t)*f_2(t)=\int_{-\infty}^{+\infty}f_1(\tau)f_2(t-\tau)\,\mathrm{d}\tau
   $$
2. **卷积定理**把时域最难算的运算变成乘法，这是第四章和第五章存在的全部理由。
3. **特征函数性质**说明 $\mathrm{e}^{st}$ 是 LTI 系统的特征函数，$H(s)$ 是特征值：
   $$
   \mathrm{e}^{st}\ \longrightarrow\ H(s)\,\mathrm{e}^{st}
   $$
   把 $s=\mathrm{j}\omega$ 代进去就是频率响应，所以 $H(\mathrm{j}\omega)$ 只是 $H(s)$ 在虚轴上的截线——这一点把第五章和第四章连成一条线。

## 全书记号约定 {.unnumbered}

本书全篇统一使用下列记号，与课堂 PPT 一致。遇到与其他教材写法不同的地方，以此表为准。

| 记号 | 含义 | 说明 |
|:---|:---|:---|
| $y(t)$ | 系统的响应 | 课本与作业原卷记作 $r(t)$，本书为与各章统一改记 $y(t)$，两者等价 |
| $u(t)$ | 单位阶跃函数 | 全篇用 $u$，不写作 $\varepsilon(t)$ |
| $\delta(t)$ | 单位冲激函数 | 强度为 1，面积为 1 |
| $y_{zi}(t)$、$y_{zs}(t)$ | 零输入响应、零状态响应 | 下标分别表示 zero-input、zero-state |
| $y_{n}(t)$、$y_{f}(t)$ | 自然响应、受迫响应 | 对应经典法的通解、特解 |
| $h(t)$、$g(t)$ | 冲激响应、阶跃响应 | $g(t)=h(t)*u(t)$ |
| $\mathcal{F}[f(t)]=F(\mathrm{j}\omega)$ | 傅里叶变换 | 正变换用 $\mathcal{F}$，反变换用 $\mathcal{F}^{-1}$ |
| $\mathcal{L}[f(t)]=F(s)$ | 拉普拉斯变换 | 必须同时写出收敛域 |
| $\mathrm{j}$ | 虚数单位 | 正体，不用 $i$ |
| $\mathrm{Sa}(x)=\dfrac{\sin x}{x}$ | 抽样函数 | 与 $\mathrm{sinc}(x)=\dfrac{\sin \pi x}{\pi x}$ 相差一个 $\pi$ 尺度，只在明确说明时混用 |
| $\omega_{0}=\dfrac{2\pi}{T}$ | 周期信号的基频 | 第 3 章课件记作 $\Omega$，是同一个量；第 5、6 章极点的虚部另用 $\omega_{i}$，不与之混用 |

## 怎么用这本书 {.unnumbered}

每章固定四节，含义如下：

- **考点清单**：一张表告诉你考什么、怎么考、多重。带 ★★★ 的必须能默写公式并独立做完例题。
- **核心概念与公式**：结论 + 成立条件 + 性质表。公式后面的括号条件不是装饰，漏了会算错。
- **典型题型与解法**：每个题型给"题型特征 / 解题步骤 / 例题 / 同类题"。例题取自附加作业并给完整解答，同类题只给关键思路——那些题请自己动手补全过程。
- **易错点**：本节最短，但考前最值钱，都是作业里真实踩过的坑。

附录 A 是专题横向对比（同一问题在三个域里分别怎么做），附录 B 是考前一天的公式速查，附录 C 是易错点总汇。
